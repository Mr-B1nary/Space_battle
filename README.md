## 🌌 Overview

**Space Battle** is a space-themed arcade shooter where every wave presents a new challenge. Dodge incoming enemies, unleash your weapons, collect upgrades, and survive long enough to face powerful bosses.

Designed as a Python game project, it combines real-time movement, projectile mechanics, enemy behaviors, power-ups, and score progression in a single playable experience.

> **Your mission:** Stay alive, destroy the enemy fleet, and beat your high score.

## ✨ Features

- **Dynamic Enemy Waves** — Fight through increasingly challenging encounters.
- **Multiple Enemy Types** — Face basic, zigzag, shooter, and tank enemies.
- **Boss Battles** — Take on powerful bosses with large health pools and dedicated health bars.
- **Power-Up System** — Collect health, shields, rapid fire, and triple-shot upgrades.
- **Responsive Controls** — Move your ship and fire projectiles in real time.
- **Score & High Score** — Earn points by destroying enemies and challenge your previous record.
- **Pause & Resume** — Take a break without losing your current run.
- **Game Over & Restart** — Jump back into the action and try again.
- **Visual Effects** — Enjoy colorful enemies, projectiles, shields, and arcade-style UI elements.

## 🎮 Gameplay

Your objective is simple: survive as long as possible.

1. Launch the game and start a new run.
2. Move your spaceship to avoid incoming enemies.
3. Fire continuously to eliminate threats.
4. Collect power-ups to improve your chances of survival.
5. Defeat bosses, earn points, and reach higher waves.
6. Beat your high score.

## 🕹️ Controls

| Key | Action |
|:---:|---|
| `W` / `↑` | Move up |
| `A` / `←` | Move left |
| `S` / `↓` | Move down |
| `D` / `→` | Move right |
| `SPACE` | Shoot / Start game |
| `P` | Pause / Resume |
| `R` | Restart after Game Over |
| `ESC` | Quit the game |

## ⚙️ Installation

### Requirements

- Python 3
- Pygame

### 1. Clone the repository

```bash
git clone https://github.com/Mr-B1nary/Space_battle.git
cd Space_battle
```

### 2. Create a virtual environment (recommended)

**Windows:**

```bash
python -m venv .venv
.venv\Scripts\activate
```

**Linux / macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install the dependency

```bash
python -m pip install pygame
```

### 4. Launch the game

```bash
python space_battle.py
```

**That's it. You're ready for battle.**
